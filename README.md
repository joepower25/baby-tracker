# Nestlog — Baby Tracker

Phone-first shared baby log for Joey and partner. Built with Next.js App Router, Tailwind, Postgres (PGlite locally), Cursor identity, and Recharts.

## Local

```bash
npm install
npm run dev
```

Open http://127.0.0.1:3000 — uses a simulated viewer and in-memory PGlite.

## Publish

Private Cursor app via `publish-app`. Partner needs app access, then joins with the invite code from **More → Caregivers**.
